PSC Vacancy Hub static website starter

Files:
- index.html: website homepage
- CNAME: intended custom domain (only effective after domain approval and DNS setup)

Important:
- Vacancy listings in index.html are demonstration/sample data, not a live official feed.
- Domain availability must be checked and registration approved at https://register.com.np/.
- Publish via a public GitHub repository and enable GitHub Pages.
- Configure DNS only after the domain is approved and added in GitHub Pages settings.
- GitHub Pages is static hosting; automated vacancy collection/email/Telegram alerts need a separate scheduled backend or service.
